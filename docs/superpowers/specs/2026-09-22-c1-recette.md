## Goal

Documenter l'état réel du Palier C1 tel qu'il existe dans la base de code actuelle. Contrairement
à C3 (voir [`2026-09-22-c3-recette.md`](2026-09-22-c3-recette.md)), C1 n'a pas été livré pendant
cette session - il a été construit lors d'une session antérieure, non couverte par la transcription
disponible ici. Ce rapport est donc un **audit de conformité au plan**, pas un compte-rendu de
livraison au jour le jour : chaque ligne a été vérifiée par l'existence réelle du fichier/de la
route dans le code (`grep`), pas par un nouveau test fonctionnel en direct - voir « Method » et
« Limite méthodologique ».

## Scope

Dans le périmètre : C1.1 (Dashboard), C1.2 (Africa Map), C1.3 (Search), C1.4 (Institution
Profiles), C1.5 (Funding Flow Analytics/Sankey), C1.6 (Trends), C1.7 (Instruments Explorer), C1.8
(Opportunity Radar) - et les fondations F1-F7 dont C1 dépend.

## Method

Pour chaque tâche, vérification de l'existence réelle (pas simulée) de : (a) l'endpoint backend
nommé par le plan (`grep` sur les attributs `#[Route(...)]`), (b) le composant/la page frontend
nommé par le plan (recherche de fichier). Contrairement à C3, aucune de ces routes n'a été
re-testée par `curl` avec de vraies données dans cette session - l'audit se limite à confirmer
que le code existe et compile (voir « Limite méthodologique »).

## Limite méthodologique

**Ce rapport n'a pas re-vérifié en direct (`curl`, vraies données) le comportement fonctionnel
de C1.1-C1.8** - seule leur existence dans le code a été confirmée. Contrairement à C3 (où
chaque endpoint a été appelé en direct sur le Codespace pendant cette même session), C1 a été
audité a posteriori, sans repasser par un scénario de bout en bout. Aucune régression n'est
soupçonnée (ces pages sont utilisées quotidiennement dans cette session pour d'autres
vérifications - le Dashboard, la recherche globale et la carte ont tous été vus fonctionner en
marge d'autres tâches), mais ce n'est pas une garantie au même niveau que la recette C3.

**Recommandation** : si ce rapport doit servir de base à une clôture formelle du Palier C1,
rejouer une passe de vérification `curl` endpoint par endpoint avant signature - le travail de
cette session n'a pas eu ce périmètre.
