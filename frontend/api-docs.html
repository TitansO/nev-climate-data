Documentation API

Intégrez les données NEV Climate Data dans vos applications via l'API REST.

Présentation

L'API NEV Climate Data expose les données climatiques et de financement de la plateforme au format JSON, sous le préfixe /api. Elle est actuellement en fondations (Phase A1) : l'authentification et la gestion des clés d'accès sont opérationnelles ; les endpoints de données métier (extraction, agrégats, recherche) seront ajoutés en Phase A2.

Ouvrir la documentation Swagger / OpenAPI

Lien relatif au backend (/api/doc) - servi par le même serveur que l'API, généré automatiquement depuis le code (NelmioApiDocBundle).

Authentification JWT

Un compte utilisateur s'authentifie par identifiants (email / mot de passe) pour obtenir un jeton d'accès de courte durée et un jeton de rafraîchissement.

POST /api/auth/login
POST /api/auth/refresh
GET /api/auth/me
POST /api/auth/logout

Clés API

Une fois connecté, un utilisateur peut générer ses propres clés API pour un accès programmatique via l'en-tête X-API-Key, sans jeton JWT.

POST /api/api-keys
GET /api/api-keys
DELETE /api/api-keys/{id}

La clé brute n'est affichée qu'à la création - elle doit être sauvegardée immédiatement.

Exemple d'appel

curl -H "X-API-Key: nev_<votre_cle>" \
  https://api.nev-climate-data.org/api/auth/me

Les endpoints de données (extraction, filtres, agrégats) ne sont pas encore disponibles - ils seront documentés ici lors des tâches A2.1 (backend) et suivantes.
